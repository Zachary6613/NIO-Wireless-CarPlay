# 嘉立创 PCBA 下单说明

## 首单建议

- 数量：先做 5 片 PCB，贴装 2-5 片。
- 板材：FR-4、2 层、1.6 mm、1 oz。
- 表面处理：无铅喷锡可用于验证；若更在意 XDFN 平整度，可选沉金。
- 阻焊/丝印颜色不影响功能。
- 单面 SMT：仅顶层贴装 U1、C1、R1、R2。
- J1 不贴装（DNP），回来后将 2x3 母座焊在 PCB 底面。
- TP1-TP4 是裸铜测试点，不是实体物料。

## 上传文件

1. PCB/Gerber：`../MFI-Pi4-MiniHat-Gerbers.zip`
2. BOM：`JLCPCB-BOM.csv`
3. CPL：`JLCPCB-CPL.csv`

## 元件匹配必须逐项确认

- U1 -> C33770534 / MFI343S00177-L / XDFN 2x3 mm / 8 pins。
- C1 -> C14663 / 100 nF / 0603 / X7R。
- R1,R2 -> C114659 / 12 kOhm / 0603 / 1%。
- J1 必须设为不贴装，除非另行确认通孔手插件方向。

## 贴片预览重点

- U1 Pin 1 必须对着 PCB 上 U1 左上侧的白色圆点。
- U1 的 8 个侧焊盘和中央裸露焊盘必须完全对齐。
- C1/R1/R2 无极性，旋转 180 度不影响电气功能。
- 预览中的板尺寸应为 20 x 12 mm。
- 不允许系统把 U1 自动替换成相似封装或其他料号。

## 到货后

先不要插树莓派。使用万用表检查 3V3-GND 无短路，再给空载板限流供电；确认 3.3 V 后焊接
J1，并再次确认 Pin 1 方向。首次连接树莓派时运行项目中的 `scripts/check-mfi.sh 1`。
